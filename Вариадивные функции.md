Вариадивные функции – это функции, способные принимать переменное количество аргументов определенного типа. Этот механизм избавляет вызывающую сторону от необходимости вручную создавать и передавать слайс, если нужно обработать набор однотипных данных.

В сигнатуре функции такой параметр обозначается многоточием `...`. Внутри тела функции этот параметр ведет себя как обычный слайс (slice).

```go
func sum(nums ...int) int {
    total := 0
    // nums внутри функции имеет тип []int
    for _, n := range nums { 
        total += n 
    }
    return total
}

// Допустимы любые варианты вызова:
// sum()         -> вернет 0
// sum(5)        -> вернет 5
// sum(1, 2, 3)  -> вернет 6
```

#### 1. Строгие правила синтаксиса
Компилятор Go накладывает два жестких ограничения на использование вариадивных параметров:
1. **Только последний параметр может быть вариадивным.** Вы не можете указать переменное число аргументов в начале или середине сигнатуры.
2. **В функции может быть только один вариадивный параметр.**

```go
// ОШИБКА КОМПИЛЯЦИИ: syntax error: unexpected ..., expecting ) or comma
func process(prefix string, values ...int, suffix string) {} 

// ПРАВИЛЬНО:
func process(prefix string, suffix string, values ...int) {}
```

#### 2. Распаковка существующего слайса (Slice Unpacking)
Частая ситуация: у вас уже есть готовый слайс данных, и вы хотите передать его в вариадивную функцию. Передача слайса напрямую вызовет ошибку типов, так как функция ожидает отдельные элементы, а не сам слайс.

Для решения этой проблемы используется **оператор распаковки** (многоточие после переменной при вызове):

```go
func main() {
    nums := []int{10, 20, 30}
    
    // Ошибка: cannot use nums (variable of type []int) as int value
    // sum(nums) 
    
    // Правильно: распаковываем слайс в отдельные аргументы
    total := sum(nums...) 
}
```

#### 3. Под капотом: пустые вызовы и `nil`
Что произойдет, если вызвать вариадивную функцию вообще без аргументов? Компилятор не создает пустой слайс `[]int{}`. Вместо этого внутри функции параметр будет равен **`nil`**.

Это важная особенность Go: итерация по `nil`-слайсу с помощью `for ... range` абсолютно безопасна и просто не выполнит ни одной итерации.

```go
func printInfo(items ...string) {
    fmt.Printf("Длина: %d, Это nil: %t\n", len(items), items == nil)
}

func main() {
    printInfo()                // Длина: 0, Это nil: true
    printInfo("a")             // Длина: 1, Это nil: false
    printInfo([]string{}...)   // Длина: 0, Это nil: false (передан пустой, но инициализированный слайс)
}
```

#### 4. Производительность и распределение памяти
При каждом вызове вариадивной функции с перечислением аргументов (например, `sum(1, 2, 3)`) компилятор Go выделяет память под новый массив в куче (heap) или на стеке (в зависимости от escape-анализа) и копирует туда переданные значения, создавая слайс.

Если вы вызываете такую функцию внутри «горячего» цикла (tight loop) и у вас уже есть слайс с данными, **всегда используйте распаковку `slice...`**. Это позволит избежать лишних аллокаций памяти, так как функция будет работать с заголовком уже существующего слайса.

#### 5. Типизация и `any` (interface{})
Вариадивные параметры часто используются для создания функций, принимающих любые типы данных (как `fmt.Println`). В таких случаях используется тип `any` (алиас для `interface{}`).

```go
func logAll(prefix string, args ...any) {
    fmt.Printf("[%s] ", prefix)
    for _, arg := range args {
        fmt.Printf("%v ", arg)
    }
    fmt.Println()
}

// Вызов: logAll("INFO", 42, "пользователей", true)
```

#### Упражнение 1: Предсказать вывод
Проанализируйте код ниже. Что именно будет выведено в консоль? Обратите внимание на разницу между пустым вызовом и передачей пустого слайса.
```go
func check(items ...int) {
    if items == nil {
        fmt.Println("NIL")
    } else if len(items) == 0 {
        fmt.Println("EMPTY")
    } else {
        fmt.Println("HAS DATA")
    }
}

func main() {
    check()
    
    emptySlice := []int{}
    check(emptySlice...)
    
    var nilSlice []int
    check(nilSlice...)
}
```

#### Упражнение 3: Написание кода (Кастомный форматер)
Напишите вариадивную функцию `joinWithSeparator(separator string, parts ...string) string`.
Функция должна объединять переданные строки, вставляя между ними указанный сепаратор. 
*Требования:*
- Если `parts` не передан (пустой вызов), функция должна вернуть пустую строку.
- Не используйте встроенную функцию `strings.Join` (реализуйте логику самостоятельно для тренировки работы со слайсами и циклами).
- Обработайте случай, когда передан только один элемент (сепаратор не должен добавляться в конце).
