# Основы языка Go: От синтаксиса к архитектуре простых программ

## 1. Основы синтаксиса Go

Синтаксис Go отличается минимализмом и строгостью. Каждая программа на Go состоит из пакетов (__packages__). Выполнение программы всегда начинается с пакета `main`.

- **Пакеты и импорты**: Код организуется в пакеты для переиспользования. Для использования стороннего или стандартного функционала применяется ключевое слово `import`.
- **Видимость идентификаторов**: В Go отсутствуют классические модификаторы доступа (private/public). Экспортность определяется регистром первой буквы. Имена, начинающиеся с заглавной буквы (например, `Println`), экспортируются и доступны из других пакетов. Со строчной буквы – скрыты в пределах текущего пакета.
- **Форматирование**: В экосистеме Go принят единый стандарт форматирования кода. Утилита `gofmt` (и `goimports`) автоматически приводит код к общепринятому виду, избавляя разработчиков от споров о стиле.
- **Точка входа**: Функция `main()` не принимает аргументов и не возвращает значений. Она является точкой запуска исполняемого файла.

**Пример:**
```go
package main // Объявление пакета main

import "fmt" // Импорт пакета для форматированного ввода-вывода

func main() {
    fmt.Println("Добро пожаловать в язык Go!")
}
```

## 2. Работа с переменными и типами данных

Go является строго типизированным языком. Переменные могут быть объявлены двумя основными способами:

- **Полное объявление**: С использованием ключевого слова `var`.
    ```go
    var status string = "Активен"
    var count int = 42
    ```
- **Краткое объявление**: Оператор `:=` используется только внутри функций. Тип данных выводится автоматически (вывод типов).
    ```go
    temperature := 36.6 // Тип float64
    isAdmin := true     // Тип bool
    ```
    *Важно:* Оператор `:=` требует, чтобы хотя бы одна переменная в левой части была новой. Это позволяет элегантно переиспользовать существующие переменные: `result, err := step1()`, а затем `result, err = step2(result)`.

### Основные типы данных и их характеристики

- **Целочисленные типы с фиксированным размером**:
  - `int8` / `uint8` (alias `byte`): 1 байт.
  - `int16` / `uint16`: 2 байта.
  - `int32` / `uint32` (alias `rune`): 4 байта.
  - `int64` / `uint64`: 8 байт.
- **Базовые типы с размером, зависящим от архитектуры**: `int`, `uint`, `uintptr` (обычно 8 байт на 64-битных системах).
- **Числа с плавающей точкой**: `float32` (одинарная точность) и `float64` (двойная точность, рекомендуется по умолчанию).
- **Строки и кодировки**: Строки в Go неизменяемы (immutable) и хранятся в кодировке UTF-8. Из-за этого длина строки (`len(str)`) возвращает количество *байтов*, а не символов. Для работы с отдельными символами (особенно кириллицей или эмодзи) используется тип `rune` (кодовая точка Unicode). Итерация по строке с помощью `range` автоматически декодирует байты в `rune`.
- **Нулевые значения (Zero Values)**: Неинициализированные переменные в Go не содержат "мусор". Они получают предсказуемое нулевое значение: `0` для чисел, `""` для строк, `false` для bool и `nil` для указателей, слайсов, словарей и каналов.

### Коллекции: Слайсы и Словари (Maps)
- **Слайсы (Slices)**: Динамические массивы, которые являются надстройкой над статическими массивами. У слайса есть длина (`len` – количество элементов) и вместимость (`cap` – размер базового массива). Функция `append` используется для добавления элементов, автоматически расширяя вместимость при необходимости.
    ```go
    numbers := []int{1, 2, 3}
    numbers = append(numbers, 4, 5) // Слайс динамически расширяется
    ```
- **Словари (Maps)**: Хранят пары «ключ-значение». Ключи должны быть сравниваемого типа (например, строки или числа). Инициализация пустого словаря требует использования `make` или литерала, иначе возникнет паника при записи.
    ```go
    ages := make(map[string]int)
    ages["Анна"] = 25
    // Идиоматичная проверка наличия ключа
    age, exists := ages["Иван"]
    if !exists {
        fmt.Println("Ключ не найден")
    }
    ```

## 3. Управление потоком выполнения

В языке Go намеренно сокращено количество конструкций для управления потоком, что делает код более читаемым.

- **Конструкция `if`**: Поддерживает стандартную форму, а также инициализацию переменной прямо перед проверкой условия (область видимости переменной ограничивается блоком `if-else`).
    ```go
    if err := doSomething(); err != nil {
        // Обработка ошибки
    }
    ```

- **Конструкция `switch`**: В отличие от C или Java, в Go не требуется использовать оператор `break` в конце каждого `case` (он подразумевается по умолчанию). Если «проваливание» в следующий блок все же необходимо, используется ключевое слово `fallthrough`. Также `switch` может использоваться без условия для замены цепочек `if-else`.

- **Циклы (`for`)**: В Go существует только один оператор цикла.
    ```go
    // Классический for
    for i := 0; i < 5; i++ { ... }
    // Аналог while
    for condition { ... }
    // Бесконечный цикл
    for { ... }
    // Итерация по слайсу, словарю или строке (range)
    for index, value := range mySlice { ... }
    ```

- **Метки (Labels) и прерывание циклов**: Ключевые слова `break` и `continue` могут использоваться с метками для выхода из вложенных циклов или перехода к следующей итерации внешнего цикла.
    ```go
    OuterLoop:
    for i := 0; i < 3; i++ {
        for j := 0; j < 3; j++ {
            if i == 1 && j == 1 {
                break OuterLoop // Прерывает оба цикла
            }
        }
    }
    ```

## 4. Основы работы с функциями, методами и ресурсами

- **Функции и множественный возврат**: Функции в Go могут возвращать несколько значений одновременно. Это стандартный паттерн для возврата результата работы и объекта ошибки.
    ```go
    func divide(a, b float64) (float64, error) {
        if b == 0 {
            return 0, fmt.Errorf("ошибка: деление на ноль")
        }
        return a / b, nil
    }
    ```

- **Именованные возвращаемые значения**: В сигнатуре функции можно задавать имена для возвращаемых значений. Это позволяет использовать "голый" `return` (naked return), хотя для читаемости длинных функций явный возврат предпочтительнее.
    ```go
    func split(sum int) (x, y int) {
        x = sum * 4 / 9
        y = sum - x
        return // Эквивалентно return x, y
    }
    ```

- **Вариадивные функции (Varargs)**: Функции могут принимать переменное количество аргументов одного типа. В сигнатуре такой аргумент обозначается многоточием `...`. Внутри функции он доступен как слайс.
    ```go
    func sum(nums ...int) int {
        total := 0
        for _, n := range nums { total += n }
        return total
    }
    ```

- **Анонимные функции и замыкания**: Функции в Go являются объектами первого класса. Их можно присваивать переменным, передавать в качестве аргументов и возвращать. Анонимная функция может захватывать переменные из окружающей области видимости, образуя замыкание (closure).
    ```go
    func counter() func() int {
        count := 0
        return func() int {
            count++
            return count
        }
    }
    ```

- **Указатели (Pointers)**: По умолчанию Go передает аргументы в функции по значению (создавая копию). Для изменения оригинальной переменной или оптимизации памяти при передаче тяжелых структур используются указатели. Оператор `&` получает адрес переменной, а `*` – разыменовывает его.
    ```go
    func updateStatus(status *string) {
        *status = "Завершено" // Изменение значения по адресу
    }
    ```

- **Методы**: Метод – это функция, привязанная к определенному типу данных через специальный аргумент – получатель (`receiver`).
    ```go
    type User struct {
        Name string
        Age  int
    }

    // (u User) - получатель по значению (копия).
    // (u *User) - получатель по указателю (изменяет оригинал).
    func (u User) Greet() string {
        return fmt.Sprintf("Здравствуйте, %s. Ваш возраст: %d.", u.Name, u.Age)
    }
    ```

- **Управление ресурсами (`defer`)**: Конструкция `defer` откладывает выполнение функции до момента возврата из окружающей ее функции. Вызовы `defer` складываются в стек (LIFO – Last In, First Out). Это критически важно для гарантированного закрытия файлов, сетевых соединений или разблокировки мьютексов.
    ```go
    func readFile() {
        f, _ := os.Open("file.txt")
        defer f.Close() // Гарантированно вызовется в самом конце функции readFile
        // Работа с файлом
    }
    ```

## 5. Разработка простых программ и экосистема

Процесс разработки на Go включает использование системы управления модулями `go mod`.

1. **Инициализация проекта**: `go mod init имя_модуля`. Создает файл `go.mod`, отслеживающий зависимости.
2. **Запуск**: `go run main.go` (компиляция и запуск без сохранения бинарного файла).
3. **Компиляция**: `go build` (создание оптимизированного исполняемого файла).
4. **Тестирование**: Go имеет мощную встроенную систему тестирования. Команда `go test ./...` автоматически находит файлы `*_test.go` и запускает юнит-тесты.
5. **Очистка зависимостей**: `go mod tidy` удаляет неиспользуемые зависимости и добавляет недостающие.

## 6. Структуры и работа с памятью

В языке Go отсутствуют классы. Для моделирования сущностей используются структуры (`struct`).

### Объявление и инициализация
```go
type Client struct {
    Name    string  // Экспортируемое поле
    balance float64 // Скрытое поле (видно только внутри пакета)
}

// Способ А: Именованные поля (предпочтительный)
client1 := Client{Name: "Poopa", balance: 1500.50}

// Способ Б: Позиционная инициализация (уязвим к изменениям структуры)
client2 := Client{"Мария", 3000.0}
```

### Композиция вместо наследования (Встраивание)
В Go нет классического наследования. Применяется принцип композиции. Если структура встраивается анонимно, её методы «продвигаются» (promoted) на уровень внешней структуры.
```go
type Address struct { City string }
type Employee struct {
    Name string
    Address // Анонимное встраивание
}
emp := Employee{Name: "Иван", Address: Address{City: "Москва"}}
fmt.Println(emp.City) // Прямой доступ к полю вложенной структуры
```

### Выравнивание памяти (Memory Alignment) и оптимизация
Процессор считывает память «словами» (обычно 8 байт на 64-битных системах). Компилятор Go автоматически добавляет пустые байты (padding) между полями структуры для выравнивания по границам, кратным размеру поля.

**Неоптимальная структура:**
```go
type InefficientStruct struct {
    A bool   // 1 байт
    B int64  // 8 байт
    C bool   // 1 байт
}
```
Размер (`unsafe.Sizeof`) составит **24 байта**, а не 10. После `A` добавляется 7 байт пустоты, чтобы `B` начался с адреса, кратного 8. В конце добавляется еще 7 байт для выравнивания общего размера.

**Оптимизированная структура:**
```go
type EfficientStruct struct {
    B int64  // 8 байт
    A bool   // 1 байт
    C bool   // 1 байт
}
```
Размер составит **16 байт** (8 байт на `B`, 2 байта на `A` и `C`, и 6 байт финального пустого пространства). Группировка полей от больших к меньшим экономит оперативную память.

### Теги полей (Struct Tags)
Теги – это метаданные в обратных кавычках, которые игнорируются компилятором, но считываются во время выполнения (через `reflect`) библиотеками сериализации (JSON, XML, BSON).
```go
type User struct {
    ID       int    `json:"id"`
    Password string `json:"-"` // Скрыто при маршалинге в JSON
}
```

## Итоговый пример программы

```go
package main

import (
    "fmt"
    "strings"
)

type Task struct {
    ID          int
    Description string
    IsDone      bool
}

func (t Task) GetStatus() string {
    if t.IsDone {
        return "[Выполнено]"
    }
    return "[В процессе]"
}

func ProcessTasks(tasks []Task) (int, error) {
    if len(tasks) == 0 {
        return 0, fmt.Errorf("список задач пуст")
    }
    completedCount := 0
    for _, task := range tasks {
        if task.IsDone {
            completedCount++
        }
    }
    return completedCount, nil
}

func main() {
    tasks := []Task{
        {ID: 1, Description: "Изучить синтаксис Go", IsDone: true},
        {ID: 2, Description: "Настроить окружение", IsDone: true},
        {ID: 3, Description: "Разработать REST API", IsDone: false},
    }

    fmt.Printf("Уважаемый Poopa, начинаем анализ %d задач...\n\n", len(tasks))

    completed, err := ProcessTasks(tasks)
    if err != nil {
        fmt.Println("Критическая ошибка:", err)
        return 
    }

    fmt.Println("--- Детальный отчет ---")
    for _, task := range tasks {
        formattedDesc := strings.ToUpper(task.Description)
        fmt.Printf("ID: %d | Статус: %s | Задача: %s\n", task.ID, task.GetStatus(), formattedDesc)
    }

    switch {
    case completed == len(tasks):
        fmt.Println("\nИтог: Все задачи успешно закрыты!")
    case completed > 0:
        fmt.Printf("\nИтог: Закрыто %d из %d задач. Требуется доработка.\n", completed, len(tasks))
    default:
        fmt.Println("\nИтог: Работа не начата.")
    }
}
```

## Анализ кода и поиск ошибок

В Go очень строгий компилятор. Внимательно изучите представленный ниже фрагмент кода и найдите в нём **три синтаксические/логические ошибки**, которые не позволят программе скомпилироваться.

```go
package main

import "fmt"

type User struct {
    Name string
}

func (u User) SayHello { 
    fmt.Println("Здравствуйте, " + u.Name)
}

func main() {
    user := User{Name: "Poopa"}
    user.SayHello()

    var age int := 30 
    
    result, err := calculate(10, 5)
    
    fmt.Println("Результат деления:", result)
}

func calculate(a int, b int) (int, error) {
    if b == 0 {
        return 0, fmt.Errorf("ошибка: деление на ноль")
    }
    return a / b, nil
}
```
