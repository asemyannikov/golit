# 1. Основы синтаксиса Go

Синтаксис Go отличается минимализмом и строгостью. Каждая программа на Go состоит из пакетов (__packages__). Выполнение программы всегда начинается с пакета `main`.
- Пакеты и импорты: Код организуется в пакеты для переиспользования. Для использования стороннего или стандартного функционала применяется ключевое слово `import`.
- Форматирование: В экосистеме Go принят единый стандарт форматирования кода. Утилита `gofmt` автоматически приводит код к общепринятому виду, избавляя разработчиков от споров о стиле.
- Точка входа: Функция `main()` не принимает аргументов и не возвращает значений. Она является точкой запуска исполняемого файла.
Пример:
```go
package main // Объявление пакета main
import "fmt" // Импорт пакета для форматированного ввода-вывода
func main() {
    fmt.Println("Добро пожаловать в Go, ребята!")
}
```

# 2. Работа с переменными и типами данных

Go является строго типизированным языком. Переменные могут быть объявлены двумя основными способами:
- Полное объявление: С использованием ключевого слова var.
    ```go
    var status string = "Активен"
    var count int = 42
    ```
- Краткое объявление: Оператор := используется только внутри функций. Тип данных выводится автоматически (вывод типов).
    ```go
    temperature := 36.6 // Тип float64
    isAdmin := true     // Тип bool
    ```

# Основные типы данных:
- Базовые: `bool`, `string`, `int` (зависит от архитектуры, 32 или 64 бита), `int8`, `int64`, `float32`, `float64`.
- Составные (коллекции):
    - Массивы (`Arrays`): Фиксированная длина `[5]int`.
    - Слайсы (`Slices`): Динамические массивы. Используются чаще всего. Создаются через `make([]int, 0)` или литерал `[]int{1, 2, 3}`.
    - Словари (`Maps`): Хеш-таблицы (пары ключ-значение). Создаются через `make(map[string]int)`.

# 3. Управление потоком выполнения

В языке Go намеренно сокращено количество конструкций для управления потоком, что делает код более читаемым.

- Конструкция `if`.
    Поддерживает стандартную форму, а также инициализацию переменной прямо перед проверкой условия.
    ```go
    if err := doSomething(); err != nil {
        // Обработка ошибки
    }
    ```

- Конструкция `switch`.
    В отличие от C или Java, в Go не требуется использовать оператор `break` в конце каждого `case` (он подразумевается по умолчанию). Также switch может использоваться без условия для замены цепочек `if-else`.

- Циклы.
    В Go существует только один оператор цикла – `for`. Он может выступать в роли классического цикла, цикла while или итератора по коллекциям.
    ```go
    // Классический for
    for i := 0; i < 5; i++ { ... }
    // Аналог while
    for condition { ... }
    // Бесконечный цикл
    for { ... }
    // Итерация по слайсу или словарю (range)
    for index, value := range mySlice { ... }
    ```

# 4. Основы работы с функциями и методами

- __Функции__:
    Функции в Go могут возвращать несколько значений одновременно. Это особенно полезно для возврата результата работы и объекта ошибки.
    ```go
    func divide(a, b float64) (float64, error) {
        if b == 0 {
            return 0, fmt.Errorf("ошибка: деление на ноль")
        }
        return a / b, nil
    }
    ```

- __Методы__:
    Метод – это функция, которая привязана к определенному типу данных (чаще всего к пользовательской структуре `struct`). Связь осуществляется через специальный аргумент – получатель (`receiver`).
    ```go
    type User struct {
        Name string
        Age  int
    }

    // Метод Greet привязан к типу User. 
    // (u User) - это получатель (копия структуры).
    // Если нужно изменить саму структуру, используется указатель: (u *User)
    func (u User) Greet() string {
        return fmt.Sprintf("Здравствуйте, %s. Ваш возраст: %d.", u.Name, u.Age)
    }
    ```

# 5. Разработка простых программ

Процесс разработки на Go включает использование системы управления модулями `go mod`.

1. Инициализация проекта: В корневой папке проекта выполняется команда `go mod init имя_модуля`. Это создает файл `go.mod`, который отслеживает зависимости.
2. Запуск: Код можно запустить без явной компиляции с помощью `go run main.go`.
3. Компиляция: Для создания исполняемого бинарного файла используется `go build`.





## 6. Структуры

В языке Go отсутствуют классы в традиционном понимании (как, например, в Java или C++). Для моделирования сущностей реального мира и группировки данных используются структуры (`struct`). Структура представляет собой пользовательский тип данных, который объединяет под одним именем поля (переменные) различных типов.
1. Объявление структуры: синтаксис объявления структуры начинается с ключевого слова `type`, за которым следует имя нового типа, а затем ключевое слово `struct` с блоком полей.
```go
type Client struct {
    Name    string  // Поле строкового типа
    Age     int     // Поле целочисленного типа
    Balance float64 // Поле типа числа с плавающей точкой
    IsVIP   bool    // Логическое поле
}
```
_Примечание_: Если имя поля начинается с заглавной буквы (например, `Name` ), оно становится экспортируемым (доступным из других пакетов). Если со строчной ( `name` ) – оно видимо только внутри текущего пакета.

2. Инициализация (создание экземпляров): 

    Создать переменную структурного типа можно несколькими способами.

    - __Способ А__: Именованные поля (наиболее предпочтительный)

        Позволяет задавать значения в любом порядке и явно указывает, какое поле инициализируется. Пропущенные поля автоматически получают «нулевые значения» своего типа ( `0`, `""`, `false`, `nil` ).
        ```go
        client1 := Client{
            Name:    "Poopa",
            Balance: 1500.50,
            IsVIP:   true,
            // Поле Age получит значение 0 по умолчанию
        }
        ```

    - __Способ Б__: Позиционная инициализация

        Значения передаются строго в том порядке, в котором поля объявлены в структуре. Этот способ считается уязвимым, так как изменение порядка полей в структуре приведет к ошибке логики программы.
        ```go
        client2 := Client{"Мария", 28, 3000.0, false}
        ```

    - __Способ В__: Объявление переменной с последующим заполнением

        Создается переменная с нулевыми значениями всех полей.
        ```go
        var client3 Client
        client3.Name = "Иван"
        client3.Age = 35
        ```

3. Доступ к полям и оператор «точка»

    Для чтения или изменения полей структуры используется оператор точка ( `.` ).
    ```go
    fmt.Println("Имя клиента:", client1.Name)
    client1.Balance -= 100.0 // Изменение значения поля
    ```

4. Указатели на структуры и передача в функции

    По умолчанию при передаче структуры в функцию она копируется (передается по значению). Если структура содержит много данных, копирование может быть неэффективным. Кроме того, если функция должна изменить данные клиента, необходимо передавать указатель на структуру.
    ```go
    // Функция принимает указатель на структуру (*Client)
    func Deposit(c *Client, amount float64) {
        // В Go не нужно использовать специальный оператор для разыменования указателя на структуру 
        // (как, например, -> в C++). Компилятор делает это автоматически.
        c.Balance += amount 
    }
    ```
    Для получения адреса переменной используется оператор `&`:
    ```go
    Deposit(&client1, 500.0)
    ```

5. Композиция вместо наследования (Встраивание структур)

    В Go нет классического наследования (когда одна структура наследует поля другой). Вместо этого применяется принцип композиции через анонимные поля или вложенные структуры.
    ```go
    type Address struct {
        City   string
        Street string
    }

    type Employee struct {
        Name    string
        Address Address // Композиция: структура содержит другую структуру
    }

    // Использование:
    emp := Employee{
        Name: "Александр",
        Address: Address{
            City:   "Москва",
            Street: "Тверская",
        },
    }
    fmt.Println("Город сотрудника:", emp.Address.City)
    ```

## Пример

Ниже представлена программа, объединяющая все перечисленные концепции. Она анализирует список задач, присваивает статусы и выводит отчет.
```go
package main

import (
 "fmt"
 "strings"
)

// 1. Пользовательский тип данных (структура)
type Task struct {
    ID          int
    Description string
    IsDone      bool
}

// 2. Метод структуры для получения статусной строки
func (t Task) GetStatus() string {
    if t.IsDone {
        return "[Выполнено]"
    }
    return "[В процессе]"
}

// 3. Функция с множественным возвратом (результат и ошибка)
func ProcessTasks(tasks []Task) (int, error) {
        if len(tasks) == 0 {
            return 0, fmt.Errorf("список задач пуст")
        }

        completedCount := 0
        for _, task := range tasks {
            if task.IsDone {
                completedCount++
            }
        }
        return completedCount, nil
    }

func main() {
    // Инициализация слайса структур
    tasks := []Task{
        {ID: 1, Description: "Изучить синтаксис Go", IsDone: true},
        {ID: 2, Description: "Настроить окружение", IsDone: true},
        {ID: 3, Description: "Разработать REST API", IsDone: false},
    }

    fmt.Printf("Уважаемый Александр, начинаем анализ %d задач...\n\n", len(tasks))

    // Использование функции с множественным возвратом
    completed, err := ProcessTasks(tasks)

    // Управление потоком (обработка ошибок)
    if err != nil {
        fmt.Println("Критическая ошибка:", err)
        return // Завершение функции main
    }

    // Итерация и использование метода
    fmt.Println("--- Детальный отчет ---")
    for _, task := range tasks {
        // Форматирование вывода
        formattedDesc := strings.ToUpper(task.Description)
        fmt.Printf("ID: %d | Статус: %s | Задача: %s\n", task.ID, task.GetStatus(), formattedDesc)
    }

    // Использование switch для итоговой оценки
    switch {
        case completed == len(tasks):
            fmt.Println("\nИтог: Все задачи успешно закрыты!")
        case completed > 0:
            fmt.Printf("\nИтог: Закрыто %d из %d задач. Требуется доработка.\n", completed, len(tasks))
        default:
            fmt.Println("\nИтог: Работа не начата.")
    }
}
```

# Блок вопросов

- Структура программы: Какова роль пакета `main` и функции `main`? Возможно ли запуск программы, если функция `main` находится в другом пакете?
- Переменные: В чем заключается принципиальное отличие между объявлением переменной через ключевое слово `var` и оператор краткого присваивания `:=?` В каких случаях использование `:=` недопустимо?
- Управление потоком: Как работает конструкция `switch` в Go? Требуется ли в ней явное использование оператора `break` для предотвращения «проваливания» в следующий `case`?
- Циклы: Какой оператор цикла является единственным в языке Go? Каким образом с его помощью можно реализовать бесконечный цикл или аналог цикла `while`?
- Функции и методы: Что такое «получатель» (`receiver`) в контексте методов? Чем метод структуры отличается от обычной функции?
- Обработка ошибок: Почему в Go принято возвращать ошибку как отдельное (обычно последнее) значение из функции, а не использовать механизм исключений (подобный `try-catch` в других языках)?

## Анализ кода и поиск ошибок

В Go очень строгий компилятор, который не позволяет собрать код, содержащий неиспользуемые переменные или импорты. Внимательно изучи представленный ниже фрагмент кода и найди в нём три синтаксические/логические ошибки.
```go
package main

import "fmt"

type User struct {
    Name string
}

// Ошибка 1: Нарушен синтаксис объявления метода
func (u User) SayHello { 
    fmt.Println("Здравствуйте, " + u.Name)
}

func main() {
    user := User{Name: "Poopa"}
    user.SayHello()

    // Ошибка 2: Неверный способ объявления переменной
    var age int := 30 
    
    // Ошибка 3: Строгий контроль компилятора за неиспользуемыми переменными
    result, err := calculate(10, 5)
    
    fmt.Println("Результат деления:", result)
}

func calculate(a int, b int) (int, error) {
    if b == 0 {
        return 0, fmt.Errorf("ошибка: деление на ноль")
    }
    return a / b, nil
}
```
